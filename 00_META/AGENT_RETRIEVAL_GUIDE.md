# Agent Retrieval Guide

## Authority Before Retrieval

Load current NEROZARB constitution, authority, business state, client truth, and approved SOPs before applying NotebookLM-derived guidance. All domain documents in this OS are retrieval evidence, not company authority.

## Retrieval Doctrine

- Start with one quick reference or master OS.
- Add the relevant rubric, SOP, prompt pattern, contradiction register, or benchmark file only when the task needs it.
- Open notebook-level extraction and source indexes only for provenance, edge cases, or source-specific review.
- Verify freshness-sensitive platform/model advice before live use.
- Do not apply the romantic-attraction notebook to manipulation or marketing without explicit ethical review and an inference label.
