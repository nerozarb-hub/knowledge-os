# Knowledge Improvement Loop

`Knowledge → Agent Application → Output → Evaluation → Failure Detection → Root-Cause Analysis → Relevant KB Retrieval → Proposed Rule / Prompt / SOP Change → Validation → Promotion`

## Required Improvement Record

- observed problem
- affected output
- relevant knowledge
- proposed change
- evidence
- test
- result
- decision
- updated file
- date

## Promotion Rule

Do not rewrite canonical knowledge from one poor output. Promote a change only when evidence supports the causal diagnosis, the revised rule improves the intended result, provenance remains intact, and no governing NEROZARB authority is contradicted.
