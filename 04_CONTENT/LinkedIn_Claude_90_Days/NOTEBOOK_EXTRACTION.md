## 3. Core Principles

1. **Depth of Grounding Over Prompt Engineering:** A post's failure to sound authentic or drive growth is rarely a prompt issue; it is a lack of deep grounding in personal context, real-world data, and explicit tone guidelines [1, 5, 8].
2. **Contextual Enrichment:** High-performing LinkedIn posts require the synthesis of three inputs: live web/market data (statistical backing), personal/social proof points, and an explicit brand voice file [3, 5, 8].
3. **Action-Oriented AI (Agentic Autonomy):** True leverage is achieved when the AI is not just a text generator but an agent that can interact directly with the internet, run software (Playwright CLI), and execute actions on the creator's behalf [10, 11].
4. **Closed-Loop Feedback:** Future content must be continuously shaped by analyzing past engagement data and auditing recent posts to prevent repetitive ideation [17].

## 6. SOPs (Standard Operating Procedures)

### SOP 1: Upgrading Level 1 Output with Live Web Research
1. Open Claude Chat [1].
2. Input a baseline topic (e.g., *"Write me a viral LinkedIn post about how AI is reshaping the workforce"* [2]).
3. Toggle/turn on the **Research** feature inside the Claude Chat interface [3].
4. Instruct the assistant to browse the web specifically for "hard statistics," academic papers, or corporate surveys on that theme [3, 5].
5. Ensure the hook of the post incorporates one of these qualified data points (e.g., *"Companies using ChatGPT report that 49% of them have already replaced workers because of it"* [3]).

### SOP 2: Constructing a Level 2 Claude Project (Grounding Engine)
1. Open Claude Projects and click **"New Project"** [4].
2. Name the project `LinkedIn Post Writer` [4].
3. Click the plus icon on **Instructions** and paste the Elite Ghostwriter system prompt [5, 6].
4. Prepare your foundation files (Text or Markdown files) [8]:
    *   **Tone of Voice Guidelines:** Characteristics (e.g., ancient wisdom, calm authority), sentence structure, vocabulary constraints, and rhythm [8].
    *   **Social Proof Document:** Case studies, client wins, metrics, and coaching call summaries [8, 17].
    *   **Personal Stories Document:** Narrative hooks, formative personal events, and relatable struggles [8].
5. Click **"Upload from Device"** and add all three documents to the project's files sandbox [8, 9].
6. Query the Project: *"Write me a viral LinkedIn post about how AI is changing the workforce"* [9].

### SOP 3: Building and Executing a Browser-Posting Agentic Skill (Level 3)
1. Install Claude Code on your machine.
2. Visit the Playwright website, copy the installation command, and paste it into Claude Code: `npm init playwright` or the platform-specific installer [12].
3. Tell Claude Code: *"Yo Claude, install this for me"* [12].
4. Switch Claude Code to **Plan Mode** to blueprint the skill [12].
5. Prompt Claude to create the skill: *"I need to build a skill that automatically researches the internet or Reddit based off a given topic. It writes LinkedIn posts in my tone of voice based off of my personal story and proof points, and then actually uses the Microsoft Playwright CLI to post live on LinkedIn"* [12].
6. Review the generated plan, select **"Accept and Auto Mode"**, and let Claude write the script [13].
7. Run the skill for the first time: Type `/linkedin-post` or the custom slash command `/linkedin-youtube-skill` [13, 16].
8. When the Playwright browser window pops up, **manually log in** to LinkedIn to save your cookies [14]. (This step only needs to be completed once every few months [14]).
9. Watch the script run autonomously: It will navigate to the LinkedIn home page, click "Start a post", paste the drafted text, take a screenshot of the viewport to locate the blue post button, and click it [14].

### SOP 4: Setting Up an Autonomous Level 3.5 Content Schedule
1. Open Claude Code and type `/schedule` [16].
2. Define the execution instructions: *"I want to run this LinkedIn YT post every single morning at 8 am..."* [16].
3. Feed the routine a seed list of **10 distinct industry keywords** to cycle through [16].
4. Configure the system to automatically pick one keyword daily, run the search, write the post, and publish [15, 16].

### SOP 5: Executing Level 4 Autonomous Lead Generation & Intake
1. Connect your local **Obsidian Vault** to your AI environment (representing your complete digital brain: personal stories, coaching call transcripts, testimonials) [17].
2. Direct the agent to automatically scrape Reddit to find active pain points and complaints posted by your Ideal Customer Profile (ICP) [17].
3. Instruct the agent to generate exactly **three distinct post concepts** based on the Reddit research and present them to you [17].
4. Select one concept to proceed.
5. The agent parses the Obsidian Vault to see what topics have succeeded previously and checks recent outputs to avoid duplicate themes [17].
6. The agent writes the post adhering to the structural anatomy (Pain -> Proof -> CTA) [17, 18].
7. The agent publishes the post via Playwright CLI [17, 18].
8. Ensure your **Lead Shark** platform is running with active automation listening to comments on your LinkedIn profile [18].
9. When a user leaves a comment, Lead Shark automatically triggers an in-app Direct Message containing your lead magnet or community invitation [18].

## 9. Quality Evaluation Rubric

This scorecard is designed to evaluate a generated post before manual or automated publishing:

| Criteria | High Quality (Pass) | Poor Quality (Fail) |
| :--- | :--- | :--- |
| **Hook Viability** [3, 7] | Opens with a shocking reframing, an undeniable contrarian truth, or a hard statistic cited from a research paper or corporate survey. | Opens with a generic question (e.g., "Have you ever wondered about AI?") or unbacked marketing cliché. |
| **Statistical Grounding** [3, 5] | Integrates verifiable statistics (e.g., *"49% of companies have replaced workers"*). | Lacks data, using sweeping generalizations instead (e.g., *"A lot of people are losing their jobs"*). |
| **Brand Tone Integrity** [5, 8] | Mimics the specific sentence rhythm, phrasing habits, and character traits of the founder's guidelines. | Sounds robotic, overly academic, or overly excited with corporate buzzwords. |
| **Personal Relevance** [8, 17] | Weaves in a direct personal case study, specific agency win, or authentic coaching anecdote from the creator's archive. | Reads like a textbook or a generic summary of a news article with zero personal perspective. |
| **Conversion Pathway** [17, 18] | Seamlessly connects the core problem to a concrete call to action (e.g., commenting to get a resource or joining a specific community). | Ends without a clear path forward or uses a weak "Let me know your thoughts!" call to action. |

## 10. Failure Modes & Vulnerabilities

1. **The "Yoda Trap" (Robotic Stereotyping):** When implementing extreme tone parameters (like using Yoda's voice as an experimental control), the text risks sounding like a caricature rather than a natural human [7, 9]. 
2. **Repetitive Content Loops:** Automating a daily schedule (e.g., every morning at 8:00 AM) can quickly exhaust topics and make the account sound redundant unless a broad rotation of keywords (at least 10) is actively enforced [15, 16].
3. **Cookie Expiry & Auth Blockers:** Playwright CLI depends on saved browser cookies [14]. If LinkedIn updates its authentication protocols, signs the session out, or triggers a captcha, the autonomous skill will break and fail to publish [14].
4. **Selector / Target Shifting:** The Playwright CLI relies on visual screenshots or specific selector locations to find and click the blue "Post" button [14]. If LinkedIn pushes a UI update that changes the button placement, the script's visual targeting will fail [14].

## 16. Labeled Synthesis & Strategic Inferences

> **[SYNTHESIS / INFERENCE: Brand Value vs. Account Security]**
> While the Level 3 and Level 4 automation pipelines showcase massive operational leverage, there is a severe risk profile mismatch for high-ticket agencies. An agency representing high-value enterprise accounts cannot afford the risk of a permanent LinkedIn ban resulting from browser automation (Playwright CLI). Additionally, auto-DMing commenters (Lead Shark) can lead to low-quality lead interactions that erode elite brand equity.
>
> *Strategic Action:* To retain the value of this system without the existential risk, founders should bifurcate the workflow:
> 1. Use the Level 4 **Obsidian Vault grounding + Reddit ICP scrape + Claude Project drafting** to generate high-quality, highly authentic content options.
> 2. Stop the automation before Level 3 execution. Keep a **Human-in-the-Loop** to review, manually publish, and personally message commenters, preserving genuine executive relationships.

## 17. Agent Directives (For Autonomous AI Action)

When running inside Claude Code or an agent environment, you must operate under these core directives:

1. **Verify Sandbox Files First:** Before drafting, you must search for local context. Read the `./tone_of_voice.md`, `./personal_stories.md`, and `./success_stories.md` files [5, 8]. If they do not exist, halt and notify the user to upload them.
2. **Execute Multi-Source Research:** Do not draft a post purely from parametric memory. Run an active web search for the topic, find at least one quantitative metric or statistic from a reputable source, and scrape current Reddit threads for real human complaints [3, 5, 17].
3. **Draft with Strict Structure:** Construct the content exactly around: Shocking/Statistic Hook -> ICP Pain Point -> Personal Proof Case Study -> CTA [17, 18].
4. **Respect Repetition Guardrails:** Log the title and date of every published post to `./notion_posts_log` (or equivalent file). Check this log before writing a new piece to ensure the same angle is not used more than once in a 14-day cycle [11, 17].
